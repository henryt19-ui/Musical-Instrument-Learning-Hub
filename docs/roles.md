# Proposed Roles and Responsibilities

Source: §7 of MIH draft design document. These are *role definitions*, not named individual assignments.

| Team role | Responsibility |
|---|---|
| Project Manager | Delivery, milestones, stakeholder reporting, risks, coordination |
| Solution Architect | Technical decisions, architecture review, AWS design, service contracts |
| Backend Engineers | APIs, databases/migrations, unit and integration tests, service docs |
| Frontend Engineers | Web/mobile UI, accessible components, client state, E2E UI tests |
| ML Engineer | Training, evaluation, TFLite conversion/inference optimization, benchmarks |
| DevOps / Platform Engineer | IaC (Terraform), containers/CI-CD, configuration, deployment and alerting |
| QA Engineer | Test plans, regression, load testing target 10,000 concurrent users, defects |
| Security Engineer | Threat model, penetration test coordination, OWASP/PCI considerations |
| Instructional Designer | Curriculum and learning outcomes, content quality |
| Content Operations | Video/audio production, media ingestion, metadata and quality control |

Document authors: Alex Wario, Rachel Salvatierra, Jimmy Chen, Josh Dabu, Tyler Henry, Kellan Kaiser. Team 3. Author names are not assignments to the above roles.
